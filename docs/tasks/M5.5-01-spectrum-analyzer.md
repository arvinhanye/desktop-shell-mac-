## 目标

新建一个不碰音频设备的频谱分析器：喂进系统声音的采样，吐出 12 个 0–1 的柱高。用合成的正弦波测试频段位置、上升衰减和静音判断。M5.5-02 再把它接到系统音频捕获上。

## 背景与约束

- AGENTS.md："技术选型"的系统音频一行；"技术探针"的系统音频捕获探针（48 kHz、双声道、Float32、交错存储，每次回调 512 帧；FFT 4096、hop 2048、Hann 窗、12 个对数频段 20–16500 Hz）；"省电要求"（持续静音超过 2 秒不做频谱分析、不推送）；"素材来源"里的律动参数。
- Claude Code 读过美化包里 `Skins/Lano-VisualizerL` 的配置（只当数据读）：
  - 实际分 13 个频段，跳过最低的一段。
  - 左右声道取平均（`Channel=Avg`）。
  - 每根柱子取相邻三个频段的平均（`MeasureBandsSmoothed.inc`）。
  - Lano 的"灵敏度 18"依赖 Rainmeter 插件内部的缩放，不能直接搬。下面第 3 节的映射参数由 Claude Code 用两首歌离线标定。
- 推送频率：每 2048 帧算一次，48 kHz 时约每秒 23 组（AGENTS.md 推送事件表）。网页那边 250 毫秒没有新数据才归零，不受影响。
- 只用 Foundation 和 Accelerate（vDSP）。不 import CoreAudio、AVFoundation、AppKit。

### 1. 接口（新建 `Sources/DesktopShell/SpectrumAnalyzer.swift`）

```swift
struct SpectrumParameters: Equatable {
    var fftSize = 4096
    var hop = 2048
    var minHz = 20.0
    var maxHz = 16500.0
    var bandCount = 12                   // 实际分 bandCount + 1 段，丢掉最低的一段
    var attack = 0.100                   // 秒
    var decay = 0.060                    // 秒
    var floorDB = -45.0
    var ceilingDB = -10.0
    var tiltDBPerBand = 3.0
    var tiltPivot = 6
    var neighborAverage = true
    var silenceThreshold: Float = 1e-4   // 一跳的新采样绝对值都小于它，算静音
    var silenceSeconds = 2.0
    static let lano = SpectrumParameters()
}

final class SpectrumAnalyzer {
    init(sampleRate: Double, channels: Int, parameters: SpectrumParameters = .lano)
    /// 交错的 Float32 采样，共 frameCount × channels 个。每凑满一跳算一次。
    /// 返回这次调用里产生的结果：0 个或多个，每个是 bandCount 个 0–1 的数，从低频到高频。
    func process(_ samples: UnsafeBufferPointer<Float>, frameCount: Int) -> [[Double]]
    /// 当前是否处在"静音中"（见第 2 节第 2 步）。M5.5-02 用它记录 sound=true / false。
    private(set) var isSilent: Bool
    func reset()
}
```

- 内部缓冲在 `init` 里一次分配好，`process` 里除了返回值不再分配数组。M5.5-02 每秒要调用它约 94 次。
- 不是线程安全的：同一个实例只在一个队列里使用。
- 输入里如果有 NaN 或无穷大，按 0 处理。否则平滑状态会永远变成 NaN，`bridge.js` 会拒收，律动条就一直不动了。

### 2. 每一跳的计算（按顺序）

1. **混成单声道，切窗**：多声道取平均。保留最近 `fftSize` 个采样，每来 `hop` 个新采样算一次（重叠 50%）。
2. **静音判断**：这一跳的 `hop` 个新采样，绝对值都小于 `silenceThreshold`，记为"静音跳"。
   - 初始状态是"静音中"：一开始就喂静音，不产生任何结果。
   - 有声音的跳：正常计算，返回结果。
   - 声音停了以后，照常计算并返回结果，柱子会自然衰减到 0。连续静音满 `silenceSeconds` 后进入"静音中"：**不做 FFT、不返回结果**，只检查新采样里是否又有声音。
   - 重新有声音时，先把平滑状态清零，再从这一跳恢复计算。
3. **FFT**：Hann 窗加实数 FFT（`vDSP_fft_zrip`）。每个频点的幅度要归一化成"满幅正弦波 = 1"：Hann 窗的相干增益是 0.5，所以除以 `N/4`；`vDSP_fft_zrip` 的输出是 DFT 的 2 倍，还要再除以 2。第 0 个频点（直流）不用。
4. **上升和衰减平滑**：每个频点单独平滑。
   - 公式：`smoothed = x + k × (smoothed − x)`。
   - 新值大于旧值时 `k = kAttack`，否则 `k = kDecay`。
   - `k = exp(−2 × (hop / sampleRate) / 时长)`，时长分别是 `attack`、`decay`。
   - 48 kHz 时 `kAttack ≈ 0.426`，`kDecay ≈ 0.241`。
5. **分频段**：
   - 在 `minHz…maxHz` 之间按对数等分成 `bandCount + 1` 段。边界 `e_k = minHz × (maxHz / minHz)^(k / (bandCount + 1))`，k 从 0 到 `bandCount + 1`。
   - 丢掉第 0 段，剩下的段从低到高编号 0…`bandCount − 1`。
   - 频点的中心频率是 `i × sampleRate / fftSize`，落在 `[e_k, e_{k+1})` 里就归这一段。
   - 一个频点都分不到的段（采样率低时可能出现），取离这一段几何中心最近的那个频点。
6. **频段能量**：段内各频点平滑后的幅度平方求和，换算成 `dB = 10 × log10(max(能量, 1e-12))`。
7. **倾斜补偿**：`dB + tiltDBPerBand × (段号 − tiltPivot)`。音乐的高频能量比低频小得多，补偿以后各段的典型高度接近。
8. **映射到 0–1**：`(dB − floorDB) / (ceilingDB − floorDB)`，结果夹在 0 到 1 之间。
9. **相邻平均**：`neighborAverage` 为真时，每段取自己和左右邻居共三个值的平均。最边上的一段没有外侧邻居，用自己补上，等于 Lano 的 `(Raw0+Raw0+Raw1)`。
10. **返回**：`bandCount` 个数，从低频到高频。网页把第 0 个放在靠近心形的一侧。

### 3. 参数从哪来（Claude Code 标定，2026-10-19）

- **标定方法**：用本机两首歌（一首 flac、一首 mp3，各取前 120 秒），按上面的流程离线计算。
- **结果**：
  - 各段最终数值的中位数约 0.3–0.6；最低的三段偏低，在 0.0–0.3。
  - 90% 分位约 0.5–0.88，最大值能到 1。
  - 柱子大部分时间在中间跳动，不会一直顶满，也不会贴底。
- **调参规则**：这些只是起点。M5.5-02 在桌面上目测后可能会调。**怎么调由 Claude Code 和用户决定，Codex 不自行改数值。**所有数值只在 `SpectrumParameters` 的默认值里出现一次。

### 4. 测试（新建 `Tests/DesktopShellTests/SpectrumAnalyzerTests.swift`）

全部用合成信号，不读文件，不碰音频设备。为了测试，可以开放 `internal` 的辅助函数或属性，例如频段边界、每段的频点范围、最近一次的频段 dB（倾斜补偿之前）。

- **频段边界**：48 kHz 和 44.1 kHz 下，13 个分段的边界和每段的频点数，每段至少有一个频点。
- **频段位置**：对 12 段中的每一段，在它的几何中心频率喂振幅 0.5 的正弦波 1 秒，最近一次的频段 dB（倾斜补偿之前）里这一段最大。48 kHz 和 44.1 kHz 各测一遍。不用最终的 0–1 数值判断，因为夹到 1 以后可能并列。
- **幅度归一化**：1 kHz 满幅正弦（落在频点很多的那一段里，离边界远），稳定后这一段的能量约 +1.76 dB（Hann 窗的等效噪声带宽是 1.5 个频点），允许误差 ±1 dB。
- **上升和衰减**：
  - 48 kHz 时 `kAttack`、`kDecay` 分别约 0.426、0.241，误差在 0.001 以内。
  - 正弦突然开始：第一个结果里，该段比稳定值小，几跳以后接近稳定值。
  - 正弦突然停止：该段的结果逐跳下降。
- **静音**：
  - 开头喂 3 秒静音，没有结果，`isSilent` 一直为真。
  - 喂 1 秒正弦再接静音：静音开始后 2 秒内仍有结果，并且逐渐变小；之后不再有结果，`isSilent` 变真。
  - 再来正弦，又有结果，`isSilent` 变假。
- **分块无关**：同一段信号，一次喂完和按 512 帧分块喂，得到的结果序列完全相同。
- **声道**：左右相同的双声道信号，和对应的单声道信号，结果相同。
- **异常输入**：信号里夹着 NaN 和无穷大，之后的结果仍然都是有限数。
- **输出范围**：满幅白噪声（用固定种子）喂 2 秒，每个结果都是 12 个有限数，都在 0 到 1 之间。

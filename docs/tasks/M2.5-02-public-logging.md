## 目标

用 `open` 或双击启动 `.app` 时，也能在系统日志里看到 DesktopShell 的日志原文；直接在终端运行时，终端里照样能看到。

## 背景与约束

- M2.5-01 审查时发现：`.app` 启动后，`NSLog` 写进统一日志的内容全部显示为 `(Foundation) <private>`（macOS 默认隐藏 NSLog 的动态内容）。直接运行可执行文件时，`NSLog` 会同时输出到 stderr，所以终端里能看到。
- 另一个坑：**zsh 有一个内置命令也叫 `log`**，在 zsh 里直接敲 `log stream` 会调用错的命令。文档、脚本提示和验收命令里一律写 `/usr/bin/log`。

### 1. `Log.swift`（新建）

```swift
import Foundation
import os

enum Log {
    static let subsystem = "local.desktopshell.DesktopShell"
    static func notice(_ message: String)   // 普通信息
    static func error(_ message: String)    // 出错
    /// 纯函数，供测试：生成写到 stderr 的一行，格式与 NSLog 一致
    static func stderrLine(_ message: String, date: Date, processName: String, pid: Int32) -> String
}
```

- 统一日志：用 `Logger(subsystem: Log.subsystem, category: "app")`，`notice` 走 `.notice` 级别，`error` 走 `.error` 级别；消息**必须**写成 `"\(message, privacy: .public)"`，否则仍然会被隐藏。用 `.notice` 而不是 `.info`，这样 `log show` 不加 `--info` 也能看到。
- stderr：每条日志同时写一行到 stderr，格式和 NSLog 保持一致：`yyyy-MM-dd HH:mm:ss.SSS <进程名>[<pid>] <消息>\n`（例如 `2026-10-17 06:25:20.438 DesktopShell[40167] DesktopShell power: paused=false reasons=[]`）。日期用本地时区，格式固定（`en_US_POSIX`）。
- 线程安全：`Log` 可能从后台队列调用（例如 `ShellSchemeHandler` 读文件出错时），实现不能依赖主线程。

### 2. 替换全部 `NSLog`

- `Sources/` 下目前有 21 处 `NSLog`（`AppDelegate` 7、`Bridge` 3、`WebContainer` 3、`ConfigStore` 2、`PowerMonitor` 2、`ScreenManager` 1、`ShellSchemeHandler` 1、`SystemStats` 1、`UiStateStore` 1），全部改成 `Log.notice` 或 `Log.error`：读写失败、解析失败、加载失败这类用 `error`，其余用 `notice`。
- **消息文字保持原样**，只把格式化参数改成 Swift 字符串插值。例如 `NSLog("DesktopShell power: paused=%@ reasons=%@", a, b)` 改成 `Log.notice("DesktopShell power: paused=\(a) reasons=\(b)")`，输出的文字必须和原来完全一样（审查和手动验证时一直在按这些文字查日志）。
- 不改任何业务逻辑。

### 3. `scripts/bundle.sh --open` 的两处修正

- 结束旧进程后，**等它真正退出**再 `open`：每 0.1 秒检查一次 `pgrep -x DesktopShell`，最多等 5 秒；超时就报错退出，不要启动新版本（否则 LaunchServices 可能只是激活旧实例）。
- 结束时打印的查看日志命令改为：

  ```bash
  /usr/bin/log stream --style compact --predicate 'subsystem == "local.desktopshell.DesktopShell"'
  ```

### 4. 测试（`Tests/DesktopShellTests/LogTests.swift`）

- `stderrLine`：给定日期、进程名、pid 和消息，输出与上面的格式完全一致；消息里的中文和 `%` 原样保留（不能被当成格式符）。

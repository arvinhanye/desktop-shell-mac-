## 目标

在真实桌面上把 AGENTS.md "联动规则"表 8 行逐条走一遍，每条留下日志或目测的证据。发现的问题另开修复任务（M5-03 起）。

## 背景

- M4 各任务的手动验证已经覆盖了大部分规则，但有三处没在应用里试过：**低电量**（需要电量低于 20%）、**没有配置提醒事项列表的项目**（用户的配置里只有一个项目，而且有列表）、**整点换问候语**。本任务补上，并把 8 条集中复核一次。
- 低电量用应用自带的测试开关：环境变量 `DESKTOPSHELL_FAKE_BATTERY=15` 让应用认为"用电池、15%"（`SystemStats.readBattery`），不用真的放电。
- "暂停时 Swift 停止系统音频捕获"属于 M5.5（系统音频还没接上），本任务记为"M5.5 时验证"。
- 不删除任何提醒事项（AGENTS.md "不要做的事"）；验证时新增的测试提醒由用户在"提醒事项"应用里自己处理。

## 准备（Claude Code）

1. 从最新的 `main` 打包启动应用（`scripts/bundle.sh --open`），记下启动时间。
2. 备份 `config.json`，临时加一个**没有 `remindersList`、也没有 `apps`** 的项目（例如 `{ "id": "m5-check", "name": "M5 检查", "path": "~/Desktop", "tags": [] }`），请用户点"重新加载"。

## 目标

运行 `scripts/bundle.sh` 后，在 `build/DesktopShell.app` 得到一个可以双击运行的应用：不在 Dock 里显示，带系统录音权限说明，并用固定的自签名证书 `DesktopShell Self-Signed` 签名，这样重新编译后系统权限不会失效。

## 背景与约束

- 先读 `AGENTS.md` 的"技术选型"（签名）、"开发环境"、"技术探针"（权限只授予签名的 `.app`），以及 `scripts/setup-signing.md`。
- 用法：`scripts/bundle.sh [--debug] [--adhoc] [--open]`
  - 默认用 `swift build -c release` 编译；`--debug` 改用 debug 配置（编译快，方便调试）。可执行文件的位置用 `swift build -c <配置> --show-bin-path` 获取，不要写死。
  - `--adhoc`：用 ad-hoc 签名（`codesign --sign -`），并打印警告"ad-hoc 签名每次编译都会变，系统权限需要重新授权，仅用于测试"。
  - `--open`：打包后先结束正在运行的 DesktopShell（`pkill -x DesktopShell`，没有就跳过），再 `open build/DesktopShell.app`，并打印查看日志的命令（见下）。
  - 参数可以任意组合；未知参数报错退出，并打印用法。
- 脚本写法和 `scripts/prepare-media.sh` 保持一致：`#!/bin/bash`、`set -euo pipefail`、开头 `cd` 到仓库根目录；兼容系统自带的 Bash 3.2。
- **组装**：先在 `build/` 下的临时目录里组装，全部成功后再替换掉旧的 `build/DesktopShell.app`（失败时旧的 `.app` 保持不变）。结构：

  ```
  build/DesktopShell.app/Contents/
  ├── Info.plist
  ├── PkgInfo                  # 内容为 APPL????
  ├── MacOS/DesktopShell       # 复制编译产物
  └── Resources/web/           # 复制仓库的 web/，排除 .DS_Store
  ```

  `AppPaths` 已经支持从 `Bundle.main.resourceURL/web` 读取网页，不需要改 Swift 代码。
- **Info.plist**（用 `/usr/libexec/PlistBuddy` 或 heredoc 生成，生成后用 `plutil -lint` 检查）：

  | 键 | 值 |
  |---|---|
  | `CFBundleIdentifier` | `local.desktopshell.DesktopShell` |
  | `CFBundleName` / `CFBundleDisplayName` | `DesktopShell` |
  | `CFBundleExecutable` | `DesktopShell` |
  | `CFBundlePackageType` | `APPL` |
  | `CFBundleShortVersionString` | `0.1.0` |
  | `CFBundleVersion` | `git rev-list --count HEAD` 的结果（不在 git 仓库里时用 `1`） |
  | `LSMinimumSystemVersion` | `14.0` |
  | `LSUIElement` | `true`（布尔值） |
  | `NSHighResolutionCapable` | `true`（布尔值） |
  | `NSAudioCaptureUsageDescription` | `DesktopShell 读取系统正在播放的声音的频谱，用来驱动桌面上的音频律动条；不录制、不保存任何音频。` |

- **签名**：
  - 身份名称默认为 `DesktopShell Self-Signed`，可以用环境变量 `DESKTOPSHELL_SIGN_IDENTITY` 覆盖。
  - 签名前用 `security find-identity -p codesigning` 检查这个名字是否存在（注意**不要加 `-v`**：自签名证书未受信任，加 `-v` 就找不到）。找不到时报错退出，提示"请先按 scripts/setup-signing.md 创建证书，或用 --adhoc 测试"。
  - 命令：`codesign --force --timestamp=none --sign "<身份>" build/DesktopShell.app`。**不加** `--options runtime`（不启用强化运行时，就不需要 entitlements），不加 `--deep`。
  - 签名后执行 `codesign --verify --strict --verbose=2`，并打印 `codesign -d -r-` 输出的指定要求（designated requirement）。
- **查看日志**：`.app` 用 `open` 启动后，`NSLog` 不会输出到终端。`--open` 结束时打印下面这条命令，供用户复制：

  ```bash
  log stream --style compact --predicate 'process == "DesktopShell"'
  ```

- `.gitignore` 增加一行 `build/`。

## 验收标准

**可执行的检查**（Codex 用 `--adhoc` 自测；Claude Code 用真实证书复验）：

- [ ] `bash -n scripts/bundle.sh` 通过
- [ ] `scripts/bundle.sh --adhoc` 退出码 0，并且：
  - [ ] 上面结构里的文件都存在；`diff -r web build/DesktopShell.app/Contents/Resources/web` 没有输出
  - [ ] `plutil -lint build/DesktopShell.app/Contents/Info.plist` 通过；`plutil -extract LSUIElement raw ...` 输出 `true`；`CFBundleIdentifier`、`NSAudioCaptureUsageDescription` 与上表一致

- [ ] `DESKTOPSHELL_SIGN_IDENTITY="Nonexistent Identity" scripts/bundle.sh` 退出码不为 0，提示里提到 `setup-signing.md`，并且已有的 `build/DesktopShell.app` 没有被删掉或改动
- [ ] `scripts/bundle.sh --bogus` 退出码不为 0，并打印用法
- [ ] `open build/DesktopShell.app` 后进程在运行；`log show --last 1m --predicate 'process == "DesktopShell"' | grep webDir` 显示的网页目录在 `build/DesktopShell.app/Contents/Resources/web`；然后结束进程
- [ ] `git status --short` 只显示 `scripts/bundle.sh`、`.gitignore` 和本任务单（`build/` 被忽略）
